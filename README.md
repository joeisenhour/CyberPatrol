# Moon Patrol (Cybertruck edition)

A single-file HTML5 tribute to the classic arcade game Moon Patrol with original pixel art. Open `index.html` in a browser.

- Level 1: Cybertruck. Level 2: Tesla Roadster with cold-gas thrusters (T or Down).
- Ending: reach the Starship.

Controls: Left/Right speed, Up/W/Space jump, Z/X/F fire, T/Down thrusters (level 2), M mute, P/Esc pause, Enter start.
Test shortcuts: `?level=2`, `?ending=1`, or press 2 / E on the title screen.

`screenshots/` holds previews; `ref/` holds reference material used for proportions (not used by the game).
